# Database Systems Workshop: SQL Hands-on

Welcome! We are using GitHub Codespaces so you don't have to install anything locally.

###  How to Start
1. Click the green **"Code"** button at the top right of this page.
2. Select the **"Codespaces"** tab.
3. Click **"Create codespace on main"**.
4. Wait about 2-3 minutes for the environment to build.

###  Connecting to Postgres
Once the terminal at the bottom appears:
1. Type `psql -U postgres -d workshop` and press **Enter**.
2. You are now inside the Postgres prompt! 
3. To exit the prompt at any time, type `\q`.

###  Your Task
Open `exercises.sql` in the file explorer on the left. Write your `CREATE TABLE` commands there and run them in the terminal.
